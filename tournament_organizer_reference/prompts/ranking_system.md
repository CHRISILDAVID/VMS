RANKING SYSTEM (V1)

1. Every tournament will have:
   - Skill Level: Beginner / Intermediate / Open
   - Tournament Reach: Intra Club / Inter Club / City Wide

2. Ranking points are calculated based on:
   - Tournament finish position
   - Number of participants
   - Tournament reach (Intra Club / Inter Club / City Wide)

3. Ranking Formula:
   Ranking Points = Position Points × Participant Multiplier × Tournament Reach Multiplier

4. Points will be awarded to approximately the top 50% of participants, with higher positions receiving more points.

5. Participant Multiplier:
   - if Players >= 8 then 1.0x
   - if Players >= 16 then 1.1x
   - if Players >= 32 then 1.2x
   - if Players >= 64 then 1.35x
   - if Players >= 128 then 1.5x

6. Tournament Reach Multiplier:
   - Intra Club = 1.0x
   - Inter Club = 1.2x
   - City Wide = 1.5x

7. Promotion:
   - Players are promoted based on ranking points (threshold to be decided after testing).
   - Beginner → Intermediate
   - Intermediate → Open 

8. Once promoted:
   - Player is removed from the previous ranking.
   - Player earns points only in the new ranking.
   - Previous tournament history is retained.

Future Enhancements:
- Opponent strength bonus
- Match win bonus
- Ranking validity/expiry (e.g., last 12 months)
- Best N tournaments considered for ranking
